## 실행 (Node 22.18 이상, 설치 없이 실행 가능)

```bash
cd game
```

```bash
node src/sim.ts --runs 300
```

```bash
npm install && npm test && npm run typecheck
```

## 구조

```
game/
├ data/          모든 수치(밸런스·교육 등급·과정·알바·장비·몬스터·던전·모의고사) + targets.json(목표)
├ src/
│ ├ types.ts     타입 정의(규칙의 뼈대)
│ ├ engine.ts    순수 규칙 엔진: newGame / step / fight / buy / preview*
│ ├ data.ts      JSON 로드 + 참조 무결성 검사
│ ├ rng.ts       시드 고정 난수(재현성)
│ ├ bots.ts      봇 3종(잘함·열심히·대충)
│ └ sim.ts       시뮬레이터 + 목표 판정 CLI
└ test/          단위 테스트 13개 + 밸런스 회귀 테스트 1개
```

## 밸런스를 바꾸는 법
1. `data/*.json`의 수치를 고칩니다. 코드는 건드리지 않습니다.
2. `node src/sim.ts`를 실행해 목표 통과 여부를 확인합니다.
3. 목표 자체를 바꾸려면 `data/targets.json`을 고칩니다. **목표를 정하는 것은 사람의 일**입니다.

## 실제 문항 연동 지점
`step(state, data, action, rng, resolver)`의 `resolver`가 문항 1개의 정오를 반환합니다. 화면에서는 학생이 푼 결과를 넘기고, 시뮬레이션에서는 봇이 확률로 맞힙니다. 자세한 내용은 PLAN의 Phase 3을 참고하세요.
