# PRD — 개념마을: 사탐 학습 육성 RPG

> 영상의 방식처럼 "대충 적은 콘셉트"에서 출발하되, 검증 가능한 숫자 목표를 붙인 버전입니다.
> 모든 수치는 `data/*.json`에 있고, 목표는 `data/targets.json`에 있습니다.

## 1. 한 줄 콘셉트
수험생이 된 플레이어가 140일(한 학기) 동안 **교육·알바·휴식·던전** 중 하루에 하나를 골라 실력을 키우고, 월례 모의고사를 버티고, 마지막에 **수능 본관**을 통과하는 육성 시뮬레이션입니다.

## 2. 대상과 목적
| 항목 | 내용 |
|---|---|
| 1차 사용자 | 학원 재원생(고1~고3, 사회탐구 선택자) |
| 목적 | ① 반복 문항 풀이를 게임 루프로 바꿔 **학습량 늘리기** ② 과목 편식을 규칙으로 바로잡기 ③ 학생별 학습 로그 수집 |
| 범위 밖 (v1) | 일반 판매, 결제, 다중 접속 실시간 플레이 |

## 3. 핵심 루프
```
하루 시작 → [상점: 장비 구매(하루 소모 없음)]
         → 행동 1개 선택
            ├ 교육: 과목 과정 수강(수강료) → 문항 10개 → 맞힌 만큼 숙련도 상승
            ├ 알바: 8시간 근무 → 시급 × 성공 시간 (해금 조건·쿨다운)
            ├ 휴식: 스트레스 감소
            └ 던전: 층별 몬스터와 전투 → 승리 시 골드 + 다음 던전 해금
         → (28일마다) 월례 모의고사 자동 전투
         → 다음 날
```

## 4. 규칙 (요약. 정확한 수식은 `src/engine.ts`)
- **능력치**: 법정(law)·경제(eco)·사문(soc)·윤리(eth) 숙련도와 이해력(int).
- **과목 = 전투 속성**: 몬스터는 과목 속성을 하나씩 가집니다. 그 과목의 숙련도가 곧 공격 배율입니다(`1 + 숙련도/40`). → **약한 단원이 곧 넘어야 할 벽**이 됩니다.
- **교육 등급**: 같은 과정을 6회 들을 때마다 초급 → 중급 → 고급 → 특급으로 오릅니다. 수강료는 20 → 500G로 오르고, 1문항당 상승폭은 2 → 8입니다.
- **문항 판정기**: 엔진은 `resolver(문항)`로 정오만 받습니다. 실제 게임에서는 **학생이 진짜 문항을 풀고**, 시뮬레이션에서는 봇이 확률로 맞힙니다. 학습 콘텐츠와 게임 규칙이 이 지점에서만 연결됩니다.
- **스트레스**: 교육·알바·던전을 할 때 오르고 휴식하면 내려갑니다. 50을 넘으면 정답률이 떨어지고, 100이면 **번아웃**으로 그날은 강제 휴식입니다.
- **이해력**: 정답률 보너스(최대 +15%p)와 HP 증가.
- **던전 패배**: 게임 오버가 아닙니다. 스트레스가 15 오르고, 진행한 층만큼 보상의 30%를 받습니다.
- **모의고사(라이벌)**: 28일마다 과목이 섞인 보스 2마리와 싸웁니다. 승리하면 골드와 이해력, 지면 스트레스를 받습니다.

## 5. 밸런스 목표 (봇 시뮬레이션으로 자동 검증)
| ID | 목표 | 의도 |
|---|---|---|
| T1 | 잘하는 봇 수능 통과율 ≥ 95% | 전략이 맞으면 반드시 보상 |
| T2 | 잘하는 봇 중앙 통과일 100~132일 | 너무 빨리 끝나지 않음 |
| T3 | 열심히 하는 봇 통과율 55~90% | 성실하면 대부분 통과, 단 보장은 아님 |
| T4 | 대충 하는 봇 통과율 ≤ 10% | 노력 없이는 불가 |
| T5 | 열심히 하는 봇 첫 던전 ≤ 20일 | 초반 성취감 |
| T6 | 중반 벽 비율 ≥ 1.3 | 3·4번째 던전이 1·2번째보다 오래 걸림 |
| T7 | 열심히 하는 봇의 50% 이상이 모의고사를 1회 이상 패배 | 라이벌 긴장감 |
| T8 | 잘하는 봇 모의고사 패배 평균 ≤ 1회 | 대비하면 이길 수 있음 |
| T9 | 돈은 있는데 살 게 없는 날 ≤ 30% | 돈이 끝까지 쓸모 있음 |
| T10 | 잘하는 봇 번아웃 평균 ≤ 0.5회 | 관리하면 피할 수 있음 |
| T11 | 대충 하는 봇도 첫 던전 ≤ 60일 | 이탈 방지 |
| T12 | 다음 장비를 살 돈이 없는 날 ≤ 60% | 목표가 손에 닿음 |

## 6. 비기능 요구
- 규칙 엔진은 화면·네트워크·저장소에 의존하지 않습니다. 브라우저와 Node에서 같은 코드가 돌아갑니다.
- 시드가 같으면 같은 판이 재현되어야 합니다(버그 재현용).
- 학생 개인정보: 저장 테이블에는 학원 내부 ID만 둡니다. 만 14세 미만은 법정대리인 동의를 받아야 합니다.
- 문항: 평가원·교육청 기출 원문 대신 **변형 창작 문항**을 기본으로 합니다.
- 배포: 원내 비공개로 사용하는 것이 기본입니다. 일반에 공개한다면 등급분류 또는 교육용 예외 요건을 먼저 확인합니다.
