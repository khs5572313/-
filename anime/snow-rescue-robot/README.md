# 눈 속의 등불 (The Lamp in the Snow) — three.js 셀 애니메이션 단편

**결과물: `snow-rescue-robot.html`**: three.js까지 모두 인라인한 단일 HTML 파일(약 0.8MB)이라 오프라인에서도 더블클릭하면 바로 열립니다. 길이는 약 99초이고 사운드가 들어 있습니다.

- 조작: ▶ 재생 / 스페이스 일시정지 / ←→ 5초 이동 / R 처음부터 / 하단에 마우스를 올리면 진행 바
- 테스트용 URL 파라미터: `?t=45` (해당 시각부터 시작), `?still=1` (정지 상태로 렌더)

## 구조
| 파일 | 역할 |
|---|---|
| `src/main.js` | 씬 구성, 연기 타임라인(로봇 2·3코마 / 새 1코마), 19개 샷 카메라, 손그림 이펙트, 렌더 파이프라인 |
| `src/robot.js` | 네모난 구조 로봇(모서리 모따기 장갑판, 유압, 호스, 단안 램프, 가슴 램프), 2본 IK |
| `src/birds.js` | 어미새 1마리와 새끼 3마리 |
| `src/world.js` | 눈 더미와 **얕은 눈 웅덩이**(절벽형 구덩이 대신 사용) 높이장, 붕괴 변형 |
| `src/paint.js` | 하늘·산맥·설면·종이결을 Canvas 붓 스트로크로 절차적으로 그리는 코드 |
| `src/shaders.js` | 셀 페인트, 포스터컬러 배경, 잉크 선화(깊이/노멀/ID 경계 + 색 트레스), 필름 마감(그레인·게이트 위브·할레이션·하모니 프레임) |
| `src/sound.js` | WebAudio 합성 사운드(바람, 새 울음, 램프, 유압, 붕괴, 음악) |

## 빌드
```bash
npm install
node build.mjs
```
