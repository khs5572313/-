# 삼국기 三國記

고구려·백제·신라와 수·당이 맞붙은 7세기(598~676)를 다루는 **역사 SLG + 카드 덱 전투** 웹 게임 프로토타입.

## 실행
설치·빌드가 필요 없습니다.
- `index.html`을 브라우저로 바로 열거나,
- 정적 서버로 띄웁니다: `python3 -m http.server 8000` → http://localhost:8000

## 들어 있는 것
| 영역 | 내용 |
|---|---|
| 지도 | 실제 경위도 기반 해안선·강·산맥, 도시 48곳, 육로·하천 수로·바닷길 연결 |
| 도시 유형 | 수도·평지성·산성·항구·장성 + 제안 유형 관문·군진 |
| 내정 | 인구·농업·상업·기술·성벽·민심·훈련, 자원 4종(식량·돈·철·목재), 특산품 무역/기술 전환, 건축물 23종 |
| 병력 | 기병·창병·궁병 상성, 공통 특수(공성·수군·노병), 국가별 특수(개마무사·조의선인·결사대·강궁대·화랑·천보노·부병·포차 등) |
| 인물 | 109명(실존 + 설화·야사), 통솔·무력·지력·정치, 1인 1특수능력·전용 카드, 연계 35종(합격기 포함) |
| 전투 | 카드 덱 전투, 공격·스킬 모션 26종, 자동 전투 |
| 시나리오 | 612 살수대첩 / 642 피의 해 / 645 안시성 / 660 황산벌 / 670 나당전쟁 |
| 이벤트 | 정사 29종 + 설화·야사 8종, 선택지로 역사 분기 |
