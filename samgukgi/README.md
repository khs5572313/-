# 삼국기 (三國記) — 전투 프로토타입

고구려·백제·신라를 배경으로 한 역사 SLG의 **전투 코어** 프로토타입입니다.
무장 뽑기(등용) → 3인 부대 편성 → 자동 전투까지 싱글플레이로 동작합니다.
서버·빌드·외부 라이브러리가 없으며, `index.html`을 브라우저로 열면 바로 실행됩니다.

이 폴더는 저장소의 문서 인식 도구(`docread`, `webapp`)와 독립적입니다.

## 실행

- `samgukgi/index.html`을 더블클릭해 브라우저로 엽니다.
- 진행 상황은 브라우저 저장소(localStorage)에 저장됩니다. 상단 "초기화"로 지울 수 있습니다.

## 검증

```bash
node samgukgi/tests/sim.test.js
```

데이터 정합성, 전투 재현성(같은 시드 = 같은 결과), 병종 상성, 진영 효과, 뽑기 확률·천장·10연 보장을 검사하고,
시작 편성 기준 스테이지별 승률 참고치를 출력합니다.

## 규칙 요약

| 항목 | 내용 |
|---|---|
| 무장 | 27명 (국가별 9명: 5성 3 / 4성 3 / 3성 3) |
| 능력치 | 무력(물리 공격), 지력(책략 공격·책략 방어), 통솔(물리 방어), 속도(행동 순서) |
| 병종 상성 | 창병 → 기병 → 궁병 → 창병. 유리 +20%, 불리 -15% |
| 진영 효과 | 같은 나라 3명이면 전부, 2명이면 절반. 고구려 주는 피해 +12% / 백제 능동 전법 발동률 +8%p / 신라 받는 피해 -12% |
| 전법 | 무장마다 고유 전법 1개 + 공용 전법 1개 장착(부대 안 중복 불가). 능동(확률 발동)·지휘(전투 시작 시)·특수 |
| 부대 | 선봉 → 중군 → 본영 순으로 일반 공격을 받음. **본영(대장)이 무너지면 즉시 패배** |
| 전투 | 최대 8턴, 속도 순 행동. 8턴 안에 결판이 안 나면 남은 병력 비율로 판정 |
| 뽑기 | 5성 3% / 4성 17% / 3성 80%. 50회 천장, 10연속 4성 이상 1명 보장. 중복은 돌파(최대 5) |
| 성장 | 레벨 최대 40 (레벨당 능력치 +2.5%, 병력 +100), 돌파당 능력치 +4%·병력 +3% |

## 파일 구조

| 파일 | 역할 |
|---|---|
| `js/data.js` | 무장·전법·병종·국가·스테이지 데이터와 성장 공식. 밸런스 조정은 여기서 |
| `js/battle.js` | 자동 전투 엔진. 화면과 분리된 순수 로직이며 시드 난수로 재현 가능 |
| `js/gacha.js` | 뽑기 확률, 천장, 중복 처리 |
| `js/sprites.js` | 창병·기병·궁병 부대 그림. 외부 이미지 없이 SVG로 그리고 나라 색으로 물들임 |
| `js/app.js` | 화면(전장·편성·무장·등용·전투 재생)과 저장 |
| `tests/sim.test.js` | 로직 검증과 밸런스 시뮬레이션 |

## 알아둘 점

- 스테이지는 역사 속 전장 이름만 빌린 가상 모의전입니다. 실제 전투의 참전 인물과 일치하지 않습니다.
- 양만춘·강이식·온달처럼 후대 기록이나 설화에 주로 전하는 인물은 무장 설명에 "전해진다"고 표기했습니다.
- 금화는 전장 보상으로만 얻으며 실제 결제 기능은 없습니다.
- 부대 그림은 코드로 그린 SVG입니다. 전투에서 창병은 내지르고, 기병은 적 앞까지 돌격하고, 궁병은 화살을 쏩니다. 소리는 없습니다.
