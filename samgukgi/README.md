# 삼국기 三國記

고구려·백제·신라 삼국 전쟁(590~676)을 다루는 **역사 SLG + 카드 덱 전투** 웹 게임 프로토타입. (수·당·왜는 지도 밖 세력으로 이벤트에만 등장하며 확장판에서 추가 예정)

## 실행
설치·빌드가 필요 없습니다.
- `index.html`을 브라우저로 바로 열거나,
- 정적 서버로 띄웁니다: `python3 -m http.server 8000` → http://localhost:8000

## 들어 있는 것
| 영역 | 내용 |
|---|---|
| 지도 | 실제 경위도 기반 해안선·강·산맥, 한반도·요동 도시 41곳(확장용 포함 49곳), 육로·하천 수로·바닷길 연결 |
| 도시 유형 | 수도·평지성·산성·항구·장성 + 제안 유형 관문·군진 |
| 내정 | 인구·농업·상업·기술·성벽·민심·훈련, 자원 4종(식량·돈·철·목재), 특산품 무역/기술 전환, 건축물 23종 |
| 병력 | 기병·창병·궁병 상성, 공통 특수(공성·수군·노병), 국가별 특수(개마무사·조의선인·결사대·강궁대·화랑·천보노·부병·포차 등) |
| 인물 | **고구려·백제·신라 각 100명(총 300명)** — 정사·설화·가상 인물 구분 표시, 통솔·무력·지력·정치, 1인 1특수능력·전용 카드, 연계 70종(합격기 포함) |

| 시나리오 | 고구려편: 590 온달의 맹세 · 655 여제동맹 / 백제편: 602 서동의 나라 · 660 황산벌 / 신라편: 642 대야성의 한 · 661 삼한일통 |
| 난이도·캠페인 | 쉬움·보통(기본)·어려움, 시나리오별 체감 난이도 별점, 6장 「삼국 통일 캠페인」(전공 계승, S~D 등급) |
