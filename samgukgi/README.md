# 삼국기 (三國記) — 프로토타입

고구려·백제·신라를 배경으로 한 역사 SLG 프로토타입입니다.
장수 등용 → 부대·성에 배치 → 내정으로 자원 생산 → 자동 전투까지 싱글플레이로 동작합니다.
서버·빌드·외부 라이브러리가 없으며, `index.html`을 브라우저로 열면 바로 실행됩니다.

이 폴더는 저장소의 문서 인식 도구(`docread`, `webapp`)와 독립적입니다.

## 실행과 검증

- `samgukgi/index.html`을 더블클릭해 브라우저로 엽니다. 진행 상황은 브라우저 저장소(localStorage)에 남습니다.
- 로직 검증:

```bash
node samgukgi/tests/sim.test.js
```

## 핵심 설계: 자리 4개 = 능력치 4개

장수는 통솔·무력·지력·정치 네 능력치를 가집니다.
부대에는 자리 4개, 성에는 관직 4개가 있고, 자리마다 능력치 하나를 씁니다.
**한 장수는 부대와 성 중 한 곳에만 둘 수 있습니다.**

| 능력치 | 부대 자리 | 전투 효과 | 성 관직 | 내정 효과 |
|---|---|---|---|---|
| 통솔 | 지휘 (대장) | 방어: 받는 일반 공격 피해 감소. 부대 병종은 대장의 병종 | 성주 | 민심 목표치, 매달 징병량 |
| 무력 | 전투 (선봉장) | 공격: 일반 공격·무력 전법 피해 | 수비대장 | 치안(생산 손실 감소), 성 방어(습격 방어) |
| 지력 | 책략 (군사) | 전법: 발동률, 책략 피해, 적 책략 저항 | 책사 | 외교(출전 시 원군), 기술 연구 속도 |
| 정치 | 병참 (군수관) | 사기: 시작 사기, 턴당 회복, 사기 피해 저항 | 재정관 | 농업(군량), 상업(금화) |

- 부대 수치 = 자리를 맡은 장수의 능력치 70% + 네 장수 평균 30%
- 빈 자리는 능력치 30으로 계산

## 전투 (부대 대 부대, 최대 10턴)

- 사기가 높은 쪽이 먼저 움직입니다. 매 턴 장수 4명의 전법이 확률로 발동하고, 이어서 일반 공격을 합니다.
- 피해를 입으면 사기가 깎입니다. **병력이 0이 되면 전멸, 사기가 0이 되면 병력이 남아도 패주**합니다.
- 사기가 낮으면 주는 피해도 줄어듭니다(사기 100에서 100%, 0에서 60%).
- 병종 상성: 창병 → 기병 → 궁병 → 창병. 유리 +20%, 불리 -15%.
- 진영 효과: 같은 나라 4명이면 전부, 3명이면 절반. 고구려 주는 피해 +12% / 백제 전법 발동률 +8%p / 신라 받는 피해 -12%.
- 책략 자리를 맡은 장수의 전법은 발동률 +8%p.
- 출전하면 군량(병력의 10%)을 쓰고 한 달이 지납니다. 잃은 병력의 30%는 부상병으로 돌아옵니다.

## 내정 (월 단위)

- "한 달 보내기" 또는 출전으로 한 달이 지나면 군량·금화·병력이 들어옵니다.
- 민심과 치안은 관직자의 능력치가 정한 목표치를 향해 매달 1/3씩 움직입니다.
- 민심은 생산과 징병에 곱해지고, 치안이 낮으면 생산의 일부를 잃습니다.
- 기술 4종(무기·갑주·농법·성벽, 각 최대 5레벨)을 하나 골라 연구합니다.
- 6개월마다 적이 성을 습격합니다. 습격 전력은 시간이 갈수록 커지고, 성 방어가 모자라면 금화·군량의 15%와 민심을 잃습니다.

## 그 밖의 규칙

| 항목 | 내용 |
|---|---|
| 장수 | 27명 (나라별 9명: 5성 3 / 4성 3 / 3성 3), 장수마다 고유 전법 1개 |
| 등용 | 5성 3% / 4성 17% / 3성 80%. 50회 천장, 10연속 4성 이상 1명 보장. 중복은 돌파(최대 5) |
| 성장 | 레벨 최대 40 (레벨당 능력치 +2%), 돌파당 능력치 +4%. 부대 병력 한도는 평균 레벨로 결정 |
| 전장 | 12개. 역사 속 전장 이름만 빌린 가상 모의전 |

## 파일 구조

| 파일 | 역할 |
|---|---|
| `js/data.js` | 장수·전법·병종·국가·자리·관직·기술·전장 데이터와 성장 공식. 밸런스 조정은 여기서 |
| `js/battle.js` | 자동 전투 엔진. 화면과 분리된 순수 로직이며 시드 난수로 재현 가능 |
| `js/city.js` | 내정 로직(월 수입, 민심·치안, 기술 연구, 습격) |
| `js/gacha.js` | 등용 확률, 천장, 중복 처리 |
| `js/sprites.js` | 창병·기병·궁병 부대 그림(SVG) |
| `js/app.js` | 화면(전장·부대·내정·장수·등용·전투 재생)과 저장 |
| `tests/sim.test.js` | 로직 검증과 밸런스 참고치 출력 |

## 알아둘 점

- 능력치 수치는 게임용으로 임의로 매긴 값이며 역사적 평가가 아닙니다.
- 양만춘·강이식·온달처럼 후대 기록이나 설화에 주로 전하는 인물은 설명에 "전해진다"고 표기했습니다.
- 금화는 전장 보상과 상업 수입으로만 얻으며 실제 결제 기능은 없습니다. 소리는 없습니다.
