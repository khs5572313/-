# 삼국기(三國記) 세부 시행계획

삼국시대 동북아시아(고구려·백제·신라·수·당·돌궐·왜)를 무대로 한 역사 시뮬레이션.
전쟁 → 내정 → 건설 → 외교 순으로 한 단계씩 쌓아 올린다.

- 인물 280인의 능력치·계략 근거: [ROSTER.md](ROSTER.md)
- 자동 전투 시뮬레이션 결과: [BALANCE.md](BALANCE.md)

## 0. 현재 상태 (v0.2)

| 항목 | 구현 내용 |
|---|---|

| 자동 전투 | 배치·계략·전법까지 AI가 대신 진행(전투 중 켜고 끄기 가능) |
| 덱 편성 | 진영 40인 중 10인 선택, 자동 편성 버튼 |
| 연출 | 계략 유형별 임팩트(물결·불길·번개·화살비·방패·깃발·회오리 등), 돌격 시 화면 흔들림, 불화살 |

## 2. 이후 단계

- **3단계 — 전쟁(전략 지도)**: 거점 30~40곳, 군단 편성·행군·보급, 공성전, 연합군
- **4단계 — 내정·건설**: 자원 4종, 계절 턴, 성별 시설, 장수 임명·등용
- **5단계 — 외교**: 관계도, 동맹·조공·혼인, 역사 이벤트, 진영별 승리 조건
- **6단계 — 출시·수익화**: 모바일 포장, 튜토리얼, 유료 시나리오 팩

## 3. 알려진 한계

- **S·A·A·B 고정의 부작용**: 광개토왕·김유신·당 태종처럼 네 능력이 모두 높은 인물도 하나는 B가 된다. 이 경우 "기록이 상대적으로 적은 분야"를 B로 두고 근거 칸에 밝혔다.
- **범위 확장**: 돌궐은 인물 수를 채우려고 제2제국(8세기 초)의 빌게 카간·퀼 테긴 등 5인을 넣었다. 왜는 야마토타케루·진구 황후 같은 전설 인물을 포함한다.
- **야사·논쟁 인물**: 강이식, 양만춘(이름), 겸익, 왕통, 선화공주 등은 근거 칸에 표시.
- **병종 배정은 게임상의 설정**이다. 문인의 병종에는 사료 근거가 없다.
