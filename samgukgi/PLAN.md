# 삼국기(三國記) 세부 시행계획

6~7세기 동북아시아(고구려·백제·신라·수·당·동돌궐·왜)를 무대로 한 역사 시뮬레이션.
전쟁 → 내정 → 건설 → 외교 순으로 한 단계씩 쌓아 올린다.

## 0. 현재 상태 (v0.1 — 전투 프로토타입 완료)

| 항목 | 구현 내용 |
|---|---|
| 실행 | `samgukgi/index.html`을 브라우저로 열면 바로 실행 (설치·빌드 없음) |
| 병종 | 기병·창병·궁병 3종. 기병 ▶ 궁병 ▶ 창병 ▶ 기병 (유리 ×1.5 / 불리 ×0.7) |
| 병종 특성 | 기병: 배치 즉시 돌격, 본진 피해 +25% / 창병: 피해 -10%, 기병에게 30% 반격 / 궁병: 매 턴 선제 사격 |
| 능력치 | 통솔·무력·지력·정치 4종, 등급 S·A·B·C·D |
| 등급 수치 | S 95 / A 85 / B 70 / C 55 / D 40 — **같은 등급은 누구든 같은 수치** |
| 전투 | 3갈래 길, 군령(코스트)으로 장수 카드 배치, 본진 함락 또는 전군 궤멸 시 종료 |
| 계략 | 장수별 고유 스킬 8유형(전체 피해·단일 피해·공격 강화·방어 강화·회복·혼란·사기·본진 수리) |
| 연출 | 근접 돌진 충돌, 궁병 화살 3연사, 피격 흔들림·피해 숫자, 격파 소멸, 계략 컷인 |
| 장수 | 7개 진영 63장 (이름 있는 장수 42명 + 병졸 21장) |
| 시나리오 | 관산성(554)·살수(612)·안문(615)·안시성(645)·황산벌(660)·백강(663) + 자유 대전 |
| 검증 | `node tools/simulate.js` — AI 자동 대전으로 승률·평균 턴 수 측정 |

### 능력치가 전투에서 하는 일

| 능력치 | 전투 | (예정) 내정·외교 |
|---|---|---|
| 통솔 | 병력 = 수치 × 10, 받는 피해 감소 | 치안·징병 효율 |
| 무력 | 일반 공격 피해 | 훈련·일기토 |
| 지력 | 계략 위력, 적 계략 저항 | 기술·첩보 |
| 정치 | 출전 시 아군 사기 상승 | 세수·외교 교섭 성공률 |

피해 공식: `무력 × 6 × 상성 × 병력비율(0.5~1) × 사기(0.8~1.2) × 강화 × 100/(100+통솔×0.6)`

## 1. 요청 사항 대비 수정·보완 제안

| # | 제안 | 이유 | 상태 |
|---|---|---|---|
| 1 | "통치"를 **통솔**로 표기 | 통치와 정치는 역할이 겹친다. 전투 지휘는 통솔, 나라 살림은 정치로 나누면 4개 능력치가 각각 쓸모를 갖는다. `js/data.js`의 `STATS` 한 줄로 되돌릴 수 있음 | 적용(되돌리기 가능) |
| 2 | 상성 외에 **병종별 고유 특성** 추가 | 가위바위보만 있으면 3턴 안에 수가 읽힌다 | 적용 |
| 3 | **사기** 수치 도입 | 정치 능력치의 전투 내 역할 확보, 역전 요소 | 적용 |
| 4 | **배치 비용** = 통솔·무력·지력 등급 합 | S급만 쓰는 덱을 막고 C·D급 병졸의 쓸모를 만든다 | 적용 |
| 5 | 적이 먼저 배치하고 플레이어가 대응 | 1인용에서 상성 읽기의 재미가 가장 크다 | 적용 |
| 6 | 일기토(무력 대결) | 장수 개성 강화. 같은 길에서 3턴 대치 시 발동 | 2단계 |
| 7 | 지형·날씨 카드(산성·강·평야·겨울) | 안시성·살수 같은 전투의 역사성을 규칙으로 표현 | 2단계 |
| 8 | 장수 고유 패시브(예: 계백 — 병력 30% 이하에서 공격 상승) | 같은 등급 = 같은 수치이므로 개성은 특성으로 부여 | 2단계 |
| 9 | 덱 편성 화면(총 비용 상한) | 지금은 진영별 고정 덱 | 2단계 |
| 10 | 연합군(나당 연합, 백제·왜) | 660·663년 전투의 실제 구도 | 3단계 |

## 2. 단계별 로드맵

### 2단계 — 전투 완성 (다음 작업)
1. 덱 편성: 진영 장수 중 비용 상한 안에서 9장 선택
2. 장수 패시브 특성, 일기토
3. 지형·날씨 (시나리오별 고정, 자유 대전은 선택)
4. 난이도 3단계 (AI 선후공·수읽기 깊이·본진 내구 보정)
5. 실제 장수 일러스트 교체 (`assets/portraits/`에 파일만 넣으면 반영)
6. 효과음·배경음, 저장

### 3단계 — 전쟁(전략 지도)
1. 동북아 거점 지도: 성 30~40곳을 길로 연결 (평양·사비·금성·요동성·장안·정양 등)
2. 군단 편성·행군·보급선. 군단이 만나면 카드 전투 진입
3. 공성전: 성 내구·수성 보정, 포위 턴
4. 연합군, 원군 요청

### 4단계 — 내정·건설
1. 자원 4종(식량·금·병력·민심), 계절 턴(1년 4턴)
2. 성별 시설: 농지·시장·병영·대장간·성벽·학당
3. 장수 임명: 통솔 → 징병, 지력 → 기술, 정치 → 세수
4. 장수 등용·충성도·세대 교체(6~7세기 약 150년)

### 5단계 — 외교
1. 관계도(-100~+100), 동맹·화친·조공·혼인·볼모
2. 역사 이벤트: 나제동맹 파기(553), 수의 통일(589), 연개소문 정변(642), 나당동맹(648), 동돌궐 멸망(630)
3. 진영별 승리 조건

### 6단계 — 출시·수익화
1. 모바일 포장(PWA → 스토어), 튜토리얼
2. 수익 모델 검토: 유료 시나리오 팩, 광고 제거, 장수 일러스트 스킨

## 3. 알려진 한계와 과제

- **진영 밸런스 미완**: AI 자동 대전 종합 승률이 당 약 73%, 고구려 약 72%, 왜 약 19%로 벌어져 있다. 시나리오에서는 본진 내구 배율로 일부 보정했다. 덱 편성(비용 상한) 도입 때 함께 맞춘다.
- **평균 전투 길이 약 14턴**(AI끼리 기준). 목표는 8~12턴.
- **초상은 임시 그림**: 진영·신분별 머리 장식만 다른 자동 생성 SVG.
- **등급은 게임 설정값**: 사료의 평가가 아니다. 온달(설화적 전승), 강이식(삼국사기에 없음), 양만춘(이름이 후대 기록에만 등장), 쇼토쿠 태자(업적 범위 논쟁)는 카드 설명에 표시했다.
- 7세기 왜의 기병 운용, 병종 배정 전반은 게임상의 단순화다.

## 4. 파일 구조

```
samgukgi/
  index.html            화면 뼈대
  css/style.css         카드·전장·연출 스타일
  js/data.js            등급표·병종·진영·장수·시나리오 (수치는 여기서만 고친다)
  js/engine.js          전투 규칙 (화면과 분리, Node에서도 실행)
  js/portrait.js        임시 초상 생성기
  js/ui.js              화면 그리기와 공격 모션
  assets/portraits/     실제 일러스트를 넣는 곳 (manifest.js에 id 등록)
  tools/simulate.js     AI 자동 대전 밸런스 측정
```
