## 3.5 행동력 제도와 명령·건물 정리 (v1.4)

### 행동력(政令)
「장수 1명 = 명령 1회」를 없애고 **나라별 행동력**으로 바꿨다. 장수가 50명 넘는 나라는 한 턴에 50번 명령해야 해서 지루했고, 장수 수가 곧 국력이 되는 문제도 있었다.

| 항목 | 규칙 |
|---|---|
| 계절당 행동력 | 5 + 군주 정치÷20 + 군주 통솔÷40 + 도시 수÷6 (4~16) → 보통 11~13 |
| 이월 | 남은 행동력은 최대 3까지 다음 계절로 |
| 명령 비용 | 개발·훈련·축성·이동·탐색 ⚡1 / 징병·건설·출진·외교 ⚡2 |
| 장수의 역할 | 명령은 그 도시에서 **가장 알맞은 장수가 자동으로** 맡는다(개발=정치, 기술=지력, 징병·훈련·축성=통솔). 장수의 능력치가 효과를 정한다 |
| 연속 명령 | 같은 장수가 한 계절에 거듭 맡으면 효과 100% → 75% → 50% |
| 명령 1회의 크기 | 개발 효과 ×2.2, 징병 규모 ×2.5 (명령 횟수가 줄어든 만큼 키움) |
| 난이도 | AI 행동력: 쉬움 -1 / 보통 0 / 어려움 +2 |

## 3.6 지도 가독성 (v1.4)
- 축척을 1.35배로 키웠다(경도 1° = 175px, 위도 1° = 230px).
- **도시 겹침 자동 해소**: 실제 위치를 기준으로 서로 92px보다 가까운 도시를 밀어내되, 원래 자리에서 최대 70px까지만 움직인다. 사비성·웅진성·황산벌·탄현·익산·기벌포처럼 몰려 있던 백제 도시가 떨어져 보인다.

## 3.7 도시 행동력·건물 레벨·무리 이동 (v1.5)

### 도시 행동력 — 도시가 발달할수록 할 수 있는 일이 늘어난다
v1.4의 「나라 행동력」을 **도시마다 따로** 계산하도록 바꿨다. 명령은 그 도시의 행동력을 쓴다(출진=출발 도시, 외교=수도).

| 요소 | 조건 | 행동력 |
|---|---|---|
| 기본 | 모든 도시 | +1 |
| 인구 | 5만 명마다 | +1 (최대 +3) |
| 경제 | 농업+상업 500마다 | +1 (최대 +3) |
| 기술 | 350마다 | +1 (최대 +2) |
| 민심 | 80 이상 / 40 미만 | +1 / −1 |
| 수도 | 왕궁 | +1 |
| 요새 | 산성·장성·관문·군진 | +1 (전선 요새도 출진할 수 있도록) |
| 주둔군 | 병력 1.5만 이상 | +1 |
| 관아 | 건물 레벨당 | +1 (최대 +3) |

- 한 도시의 행동력은 1~10이다. 남은 1점은 다음 계절로 넘어간다.
- 도시 화면에 「인구 +2 · 경제 +2 · 수도 +1 · 관아 +1」처럼 행동력의 내역이 표시된다.
- 예: 시작 시 서라벌 7, 상주 3, 산성 2. 개발하고 관아를 지을수록 늘어난다(시뮬레이션에서 3년 뒤 나라 합계 38 → 71).
- 비용: 개발·훈련·축성·이동·탐색 ⚡1 / 징병·건설·업그레이드·출진·외교 ⚡2.
- 명령 1회의 효과: 개발 ×1.3, 징병 규모 ×1.6.

### 건물 레벨(Lv1~3)과 새 건물
- 모든 일반 건물은 Lv3까지 올린다. 효과는 Lv2 ×1.7, Lv3 ×2.5다(관아는 레벨당 행동력 +1).
- 업그레이드 비용은 기본 비용 ×(현재 레벨+1)이고 ⚡2가 든다. Lv2는 도시 기술 250, Lv3은 500이 필요해서 기술 개발과 연결된다.
- **민가(民家)**(인구): 인구 상한 +4만, 인구 증가율 +0.4%p/계절, 민심 +1. 인구 상한은 도시 유형 기본값(수도 16만 · 평지성 10만 · 항구 8만 · 산성 5만 …)에 민가 효과를 더한 값이다.
- **관아(官衙)**(행정): 도시 행동력 +1/레벨, 민심 +1.
- 수도 건물 칸 8, 평지성 6으로 늘렸다. 수도의 전답·시전은 Lv2로 시작한다.

### 무리 이동
- 「이동」 한 번(출발 도시 ⚡1)으로 **장수를 원하는 만큼(클릭해서 선택, 모두 선택 가능)과 병력을 함께** 옮긴다. 병력 수송은 이동에 통합했다.

### 전투·AI 보정 (v1.5)
- **전투 시간 초과 규칙 수정**: 전에는 12라운드가 지나면 무조건 수비측이 이겼다. 그래서 공격측이 1.8배 병력이어도 승률이 2%였다. 이제 공격측 잔존 병력이 수비측의 1.3배를 넘으면 공격측이 이긴다. 피해량도 약 30% 올렸다.
  - 결과: 평지 항구는 1.2배로 약 80%, 산성은 약 2배가 있어야 함락된다(산성의 역사적 역할 유지).
- **AI 병력 이동 버그 수정**: 바로 옆 전선 도시로만 옮기던 것을 전선까지의 거리를 따라 한 칸씩 옮기도록 고쳤다. 요동처럼 먼 후방의 병력이 묶여 있던 문제를 해결했다.
- **서부 전선(지도 밖 수·당)**: 고구려 AI는 요동 성들에 수비대를 남긴다. 590년은 「가벼운 수비대」(598년 수 침공 전), 그 밖은 8천 이상을 유지하고 한 계절 30%만 남하한다. 사람 플레이어는 제약이 없다.
- 신라의 성 수비 보너스는 +15%에서 +8%로 낮췄다(전투 규칙이 공정해져서).

## 4. 병력

### 4.1 상성

```
   창병 ──▶ 기병 ──▶ 궁병 ──▶ 창병      유리 ×1.35 / 불리 ×0.75
```
- 창병의 「창벽」 카드: 방어막 + **기병의 공격 50% 반사**.
- 공성병: 성벽 피해 ×3~6, 야전 -20%. 수군: 수상전 ×1.4, 육전 ×0.8.

### 4.2 병종 일람

| 구분 | 병종 | 계열 | 특징 |
|---|---|---|---|
| 기본 | 기병 · 창병 · 궁병 | — | 상성 3각 |
| 공통 특수 | 공성병(충차·운제·투석) | 공성 | 공방 필요 |
| 공통 특수 | 수군 | 수군 | 조선소 필요 |
| 공통 특수(제안) | **노병(弩兵)** | 궁병 | 방어 무시 관통 사격. 궁시방 + 기술 300 |
| 고구려 | **개마무사** | 기병 | 공140·방135. 인마 모두 찰갑 (안악3호분·쌍영총 벽화) |
| 고구려 | **조의선인** | 창병 | 공130·방120. 사기 저하 면역 (※ 실체는 학계 논쟁) |
| 고구려(제안) | 말갈 기병 | 기병 | 말갈 연합군. 저렴한 고기동 기병 |
| 백제(제안) | **결사대** | 창병 | 병력이 줄수록 공격력 상승 (계백 5천 결사대에서 착안) |
| 백제(제안) | **강궁대** | 궁병 | 일제사격 +30% (게임 창작 병종명) |
| 신라 | **화랑 기마대** | 기병 | 사기 +10, 경험치 2배 |
| 신라(제안) | **천보노대** | 궁병 | 구진천의 천보노(삼국사기 문무왕 9년). 성벽 수비 +20% |
| 수·당 | 부병 중보병 / **포차대** | 창병 / 공성 | 부병제 정규군 / 645 요동성 공격의 투석기 |
| 왜 | 왜 수군 | 수군 | 백강 전투 원군 선단 |

### 4.3 병력 이미지 = 「타로풍 카드 프레임 + 병종 일러스트 + 장수 초상」
- 아치형 창 안에 병종 일러스트(기병·개마무사는 말 갑옷 비늘 패턴까지), 상단 원형 메달에 한자(騎·槍·弓·鎧·弩…), 하단 리본에 병종명, 좌하단 원형 메달에 **장수 초상**을 합성.
- 국가색으로 프레임을 칠한다: 고구려 진홍 / 백제 남색 / 신라 금색 / 당 녹색 / 수 보라.
- ※ 요청하신 「태릭 디자인」은 **타로 카드풍 프레임**으로 해석해 구현했다. 다른 뜻이었다면 알려 주시면 바꾸겠다.

### 5.5 나라 간 능력치 보정 (v1.4)
v1.3까지는 신라에 승려·여인·순국 화랑이 많아 통솔·무력 하위층이 두터웠다. 반대로 고구려에는 가상 책사가 몰려 있었다.

| 지표 | 보정 전 고구려 / 백제 / 신라 | 보정 후 |
|---|---|---|
| 통솔 평균 | 61 / 60 / 54 | 58 / 58 / 57 |
| 통솔 80 이상 | 16 / 11 / 10 | 16 / 12 / 14 |
| 무력 80 이상 | 18 / 21 / 9 | 18 / 16 / 15 |
| 지력 90 이상 | 6 / 3 / 11 | 6 / 6 / 6 |

- **방법**: 능력치마다 삼국 300명의 공통 분포를 만든다. 각 나라 안의 순위(백분위)를 공통 분포에 대응시킨 값과 원래 값을 85:15로 섞는다(`js/data/balance.js`).
- **유지되는 것**: 나라 안의 인물 순위는 그대로다. 예: 김유신 97/92/90/80 → 97/94/88/80, 을지문덕 94/80/98/82 → 97/80/98/82.
- **나라의 개성**은 능력치 대신 국가 특성·특수병과·특수능력이 맡는다.
- 원래 값(사료 기반 설계값)은 인물 정보 화면에 「원래 ○○」로 함께 표시된다.

## 6. 전투 — 카드 덱 전투

### 6.1 흐름
```
출진 편성(장수 ≤3, 병종·병력 배정)
   → 덱 생성: 병종 기본 카드 + 장수 능력치 카드 + 특수능력 카드 ×2 + 연계 합격기 ×2
   → 라운드 반복(최대 12): 공격측 턴 → 수비측 턴 → 화상·버프 처리
   → 한쪽 전멸 / 사기 0 → 종료 · 12라운드 초과 시 수비측 승
```

### 6.2 카드 종류

| 종류 | 예시 | 효과 |
|---|---|---|
| 공격 | 기병 돌격(19), 장창 찌르기(12), 조준사격(11), 일제사격(전체 9) | 무력 기반 피해 |
| 책략 | 화공(14, 화상 2턴), 매복(17), 혼란(1턴 행동 불능) | 지력 대결 |
| 방어 | 방진, 창벽(기병 반사), 안시성 사수 | 방어막(통솔 기반) |
| 강화 | 고무, 태왕의 깃발, 천가한의 친정 | 사기·공격·방어 상승 |
| 회복 | 재정비, 원군(말갈 원군·백만대군) | 병력 회복·증원 |

### 6.3 피해 공식
```
피해 = 카드위력 × 17 × √(병력/1000) × (0.55+공격능력/100)/(0.55+방어능력/100)
       × 상성 × 지형 × 사기(0.7~1.2) × 훈련(0.85~1.15) × 연계·특수능력·국가 보정 × 난수(0.9~1.1)
```
- 수비측은 도시 유형 보너스 + 성벽(성벽/1600) 보정을 받는다. 공성 카드는 성벽 보정을 무시하고 성벽을 깎는다.
- 병력이 많을수록 피해가 커지지만 제곱근이라 **소수 정예도 통한다**(계백의 결사대).

### 6.4 공격·스킬 모션
CSS/SVG 애니메이션 26종: 베기, 5연참, 돌격, 창 찌르기, 화살비, 단발 화살, 삼연시, 쇠뇌, 투석, 충차, 파도, 수공, 화염, 방어막, 성벽, 강화, 회복, 혼란, 매복, 낙뢰, 호국룡, 귀신, 연꽃, 노래(서동요), 원군 깃발, 호랑이 발톱.
연출 순서: 카드가 화면 중앙으로 날아옴 → 아군 카드가 적 쪽으로 돌진 → 대상 위에 이펙트 → 피격 흔들림 + 피해 숫자 + 「상성 유리!」 표시 → 궤멸 시 카드가 회색으로 쓰러짐.
