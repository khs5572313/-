# 삼국기(三國記) 게임 기획서 — M0 (설계 기준선)

> 버전 0.1 · 2026-11 · 이 문서의 수치는 `src/data/*.js`, `src/combat.js`와 1:1로 대응한다.

## 1. 한 줄 정의와 핵심 축

**581년 수 건국부터 698년 발해 건국까지, 고구려·백제·신라와 주변국이 한 장의 필드맵 위에서 싸우는 역사 전략 시뮬레이션.**

| 축 | 정의 | 이 문서의 위치 |
|---|---|---|
| ① 필드맵 | 헥스 지형이 전투 계산에 직접 들어가는 지도 | §3 |
| ② 무장 | 능력치·병종 적성·특기로 개성이 갈리는 인물 | §5 |
| ③ 전투 공식 | ①과 ②를 잇는 계산 구조 (가장 먼저 확정) | §4 |

이벤트·시나리오 연출은 **마지막 단계(M5)**. 모든 효과가 데이터(조건 + 수정치)로 표현되도록 설계해, 나중에 데이터만 추가하면 되게 한다.

## 3. 필드맵 설계

### 3.1 원칙
- **헥스 격자**(뾰족한 위, odd-r 오프셋). 사각 격자는 대각 이동이 왜곡되어 기병 기동 밸런스가 깨진다.
- 지형은 **장식이 아니라 계산 변수**: 이동 비용, 방어 배율, 공격 배율, 돌입 배율, 보급.

### 3.2 지형표 (`src/data/terrain.js`)

| 지형 | 이동(기/창/궁) | 방어 | 특수 |
|---|---|---|---|
| 평지 | 1/1/1 | ×1.0 | — |
| 구릉 | 2/2/2 | ×1.15 | 궁병이 구릉에서 쏘면 ×1.15 |
| 산악 | 4/3/3 | ×1.3 | 기병 공격·돌입 ×0.6 |
| 숲 | 2/2/2 | ×1.15 | 궁병 ×0.85, 기병 돌입 ×0.8 |
| 습지(요택) | 3/2/2 | ×0.85 | 기병 공격·돌입 ×0.7 |
| 하천 | 3/3/3 | ×0.8 | 하천 위에서 공격 ×0.8 |
| 바다 | 불가 | — | M2에서 수군 |
| 성 | 1/1/1 | ×1.65 | 기병 돌입 ×0.7, **자국 성 보급 2.5%/턴** |

### 3.3 이 시대 특유의 지형 요소
- **산성 방어 체계:** 요동성·안시성·백암성·신성·건안성 등. 이 시대 전쟁의 본질은 공성전이다.
- **요택:** 요하 서쪽 습지. 645년 당군 고전 지점 → 습지 칸으로 구현.
- **하천 방어선:** 요하·압록강·청천강(살수)·대동강·임진강·한강·금강·낙동강.
  → M1은 하천을 '칸'으로 처리. **M2에서 칸 경계(변)에 두는 방식으로 전환**(도하 패널티).
- **해상 루트:** 산둥 ↔ 덕물도 ↔ 백강, 대한해협. 660년 당군 상륙과 663년 백강 전투에 필요.
- **보급선:** 수 침공 실패의 핵심 원인. M4에서 구현.

### 3.4 전체 지도 제작 파이프라인 (M2)
1. 공개 고도 데이터(SRTM 등)를 받는다. 범위: 요서~규슈, 산둥 포함.
2. 스크립트로 헥스 격자에 다운샘플링 → 고도·경사로 평지/구릉/산악 자동 분류.
3. 하천·해안선은 공개 벡터 데이터로 칸 경계에 배치.
4. 손 작업은 **성·관문·도로·고대 해안선 보정**만 한다(고대 해안선은 현재와 다르므로 주의).
5. 출력 형식은 현재 시나리오의 `rows` 문자열과 같게 유지 → 엔진 코드 수정 불필요.

## 4. 전투 공식 (`src/combat.js`)

### 4.1 피해 계산
```
피해 = 공격측 병력 × 0.12
     × (공격력 / 방어력)
     × 상성계수 × 지형계수 × 사기계수(0.6 + 0.4×사기/100) × 난수(±25%)
     × 전법 발동 시 1.5

공격력 = 병종공격 × (0.5 + (무력'×0.6 + 통솔'×0.4)/100) × 적성 × (1 + 공격 수정치)
방어력 = 병종방어 × (0.5 + 통솔'/100) × 적성(절반 반영) × 지형방어 × (1 + 방어 수정치)

능력치' = 70 이하는 그대로, 70 초과분은 60%만 반영 (명장 독주 억제)
전법 발동 확률 = 5% + (지력' − 50) / 500   → 지력 70: 9%, 100: 13%
반격 = 방어측이 사거리 안이면 위 공식 × 0.5 × (1 + 반격 수정치)
```

### 4.2 병종 (`src/data/units.js`)

| 병종 | 공격 | 방어 | 이동 | 사거리 | 특징 |
|---|---|---|---|---|---|
| 기병 | 1.15 | 0.9 | 5 | 1 | 기동·돌격 |
| 창병 | 1.0 | 1.15 | 3 | 1 | 방어·반격 |
| 궁병 | 1.0 | 0.8 | 3 | 2 | 반격 없는 원거리, 근접 시 ×0.75 |

### 4.3 상성표 (공격 → 방어)

|  | 기병 | 창병 | 궁병 |
|---|---|---|---|
| **기병** | 1.0 | 0.85 | **1.2** |
| **창병** | **1.2** | 1.0 | 0.85 |
| **궁병** | 0.85 | **1.2** | 1.0 |

### 4.4 병종 적성
S ×1.12 · A ×1.06 · B ×1.0 · C ×0.9 · D ×0.8 (공격에 전부, 방어에 절반 반영)

### 4.5 밸런스 목표와 현재 측정값 (`npm run balance`, 200판)

| 항목 | 목표 | 측정 |
|---|---|---|
| 같은 능력치, 상성 유리 1:1 | 75% 이상 | 창>기 100%, 기>궁 100%, 궁>창 89% |
| 같은 병종 미러전 | 40~60% | 48~53% |
| 명장(무력·통솔 90, 적성 S) 역상성 | 대략 50% | 45% |
| 명장(100, S) 역상성 | 우세 | 85% |
| 능력치 80 vs 70 (같은 병종) | 70~80% | 77% |
| 645 안시성 AI 대 AI | 40~60% | 당 49% / 고구려 52% |

**설계 의도:** 평범한 장수끼리는 상성이 승부를 가르고, 최상급 명장은 상성 불리를 뒤집을 수 있다.
→ "누구에게 어떤 병종을 맡기느냐"가 핵심 의사결정이 된다.

### 4.6 확인된 리스크
- **1:1은 결정적이다.** 병력 10% 우위만 있어도 1:1 승률 93%. 실제 게임은 다부대 전투라 희석되지만, M4 내정에서 병력 격차가 너무 쉽게 벌어지지 않게 해야 한다.
- **공성 밸런스가 민감하다.** 성 방어 1.6→1.65, 보급 2.5→3%만 바꿔도 시나리오 승률이 20~30%p 출렁인다. M2에서 성 내구도(성벽 HP)와 공성 병기를 도입해 '병력 = 성 방어력' 구조를 분리해야 안정된다.

## 5. 국가 버프와 무장 특기

### 5.1 원칙 (결정 사항)
- **국가별 특수 병종은 두지 않는다.** 국가의 색깔은 병종을 가리지 않는 **국가 전체 버프**로 표현한다.
- **병종 특화(개마무사·장창·강노 등)는 무장 특기**로 둔다. 그 특기를 가진 무장이 해당 병종을 이끌 때만 발동한다.
- 국가 버프와 특기는 **같은 형식**(`{stat, value, cond}`)이라 하나의 수정치 엔진(`src/modifiers.js`)으로 처리한다. 이벤트 효과도 같은 형식으로 추가한다.

### 5.2 국가 전체 버프 (`src/data/nations.js`)

| 국가 | 버프 | 효과 |
|---|---|---|
| 고구려 | 산성의 나라 | 자국 영토의 성·산악·구릉 방어 +15%, 자국 영토에서 사기 감소 −15% |
| 백제 | 해상 왕국 | 바다·하천에 닿은 칸에서 공격 +10%, 이동 +1 |
| 신라 | 화랑도 | 사기 최저 30 보장(사기 붕괴 없음), 사기 회복 +3/턴 |
| 수 | 대운하의 대군 | 병력 +25%, 영토 밖 사기 감소 +20% |
| 당 | 중원의 대군 | 병력 +20%, 영토 밖 사기 감소 +15% |
| 왜 | 바다 건너온 원군 | 바다·하천에 닿은 칸에서 공격 +8% |
| 말갈 | 백산의 기마 | 모든 부대 이동 +1 |

### 5.3 무장 특기 (`src/data/skills.js`)

| 특기 | 발동 조건 | 효과 |
|---|---|---|
| 개마무사 | 기병 지휘 | 공격 +20%, 방어 +10% |
| 돌격 | 기병, 이동 후 공격 | 공격 +15% |
| 질풍 | 기병 지휘 | 이동 +1 |
| 장창진 | 창병 지휘, 상대가 기병 | 방어 +10%, 반격 +30% |
| 강노 | 궁병 지휘 | 사거리 +1 |
| 신궁 | 궁병 지휘 | 공격 +20% |
| 철벽 | 성 안 | 방어 +25% |
| 화랑 | 항상 | 시작 사기 +10, 사기 감소 −20% |
| 불굴 | 항상 | 사기 감소 −30% |
| 결사 | 병력 30% 미만 | 공격 +25% |

조건 키: `unitType`, `vsUnitType`, `terrain`, `ownTerritory`, `role(attack/counter/defend)`, `afterMove`, `nearWater`, `troopsBelow`.

## 6. 무장 데이터 구조 (`src/data/generals.js`)

```js
kim_yusin: {
  name: '김유신', hanja: '金庾信', nation: 'silla',
  born: 595, died: 673,           // 사서로 확정될 때만, 아니면 null + note
  historicity: '사서',             // 사서 | 후대전승 | 가상
  note: '660년 황산벌 전투 신라군 지휘',
  lead: 96, war: 90, int: 88, pol: 80, cha: 90,   // 게임 설계값
  aptitude: { cavalry: 'S', spear: 'S', archer: 'A' },
  skills: ['hwarang', 'dolgyeok'],
}
```

**원칙**
- 능력치는 게임 설계값이다. 사료 수치가 아님을 명시한다.
- `historicity`로 사서 인물·후대 전승·가상 인물을 구분한다(예: '양만춘'은 후대 전승 → '안시성주'로 표기).
- 117년의 세대교체를 위해 생몰·등장 연도 필드를 반드시 둔다.
- 사료 분량 불균형(신라 > 고구려 > 백제)은 가상 무장으로 보충하되, 반드시 `가상`으로 표시한다.
