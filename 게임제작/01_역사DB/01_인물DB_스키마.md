# 1-2. 인물 DB 스키마

한 인물 = JSON 객체 1개. 세력별 파일 `인물/고구려.json` 등에 배열로 저장한다.
키는 영문(코드에서 쓰기 쉽게), 값과 설명은 한글.

## 필드 정의

| 필드 | 형식 | 필수 | 설명 |
|---|---|---|---|
| `id` | 문자열 | ✅ | 영문 고유 ID. 예: `kim_yusin` |
| `name` | 문자열 | ✅ | 게임 표기명. 예: `김유신` |
| `hanja` | 문자열 | ✅ | 한자 표기. 예: `金庾信` |
| `alias` | 배열 | | 다른 이름. 예: 연개소문 → `["淵蓋蘇文", "泉蓋蘇文(당 측 피휘 표기)"]` |
| `faction` | 문자열 | ✅ | `goguryeo` `baekje` `silla` `sui` `tang` `tujue` `wa` `balhae` |
| `subFaction` | 문자열 | | 세력 내 파벌. 예: `gaya`(가야계), `royal_jingol`, `soga` |
| `rank` | 문자열 | | 신분. 예: `진골`, `6두품`, `대대로가문` |
| `born` / `died` | 정수 또는 `null` | ✅ | 생몰년. 모르면 `null` |
| `bornNote` / `diedNote` | 문자열 | | 이설·추정 근거 |
| `active` | `[시작, 끝]` | ✅ | 게임에 등장하는 연도 범위 (근거 사건 기준) |
| `firstRecord` | 문자열 | ✅ | 처음 기록된 사건과 연도 |
| `offices` | 배열 | | `{ "year": 642, "title": "압량주 군주", "src": "SGSG" }` |
| `relations` | 배열 | | `{ "to": "kim_chunchu", "type": "처남·매부", "src": "SGSG" }` |
| `keyEvents` | 배열 | ✅ | `{ "year": 660, "event": "황산벌 전투", "role": "신라군 총사령", "src": [...] }` |
| `stats` | 객체 | ✅ | `command` `might` `intellect` `politics` `charisma` (1~100) |
| `statBasis` | 객체 | ✅ | 능력치마다 근거 한 줄. 1-4 기준표의 규칙 번호를 단다 |
| `traits` | 배열 | | 특성. 예: `산성방어`, `수군지휘`, `외교`, `불교` |
| `signatureCards` | 배열 | | 고유 카드 ID (2단계에서 연결) |
| `loyaltyBase` | 정수 | | 기본 충성도 (파벌 시스템 연동) |
| `sourceReliability` | `S/A/B/C/X` | ✅ | 이 인물 기록 전체의 최고 등급 |
| `bias` | 배열 | | 편향 표시. 예: `가문미화(행록 기반)`, `중국중심서술` |
| `legendOnly` | 불리언 | | 전승으로만 있는 내용이 있으면 `true` → 도감에 「전승」 표시 |
| `sources` | 배열 | ✅ | 사료목록의 출처 표기 규칙 형식 |
| `note` | 문자열 | | 게임 디자인 메모 |

## 예시 (형식 확인용, 수치는 1-4 기준표 확정 후 재산정)

```json
{
  "id": "kim_yusin",
  "name": "김유신",
  "hanja": "金庾信",
  "faction": "silla",
  "subFaction": "gaya",
  "rank": "진골(금관가야 왕족 후손)",
  "born": 595,
  "died": 673,
  "active": [609, 673],
  "firstRecord": "609년 화랑이 됨 (15세)",
  "relations": [
    { "to": "kim_seohyeon", "type": "부", "src": "SGSG" },
    { "to": "kim_muryeok", "type": "조부", "src": "SGSG" },
    { "to": "munhui", "type": "누이 (김춘추의 부인, 문명왕후)", "src": "SGSG" },
    { "to": "kim_heumsun", "type": "아우", "src": "SGSG" },
    { "to": "kim_wonsul", "type": "아들 (석문 전투 후 의절)", "src": "SGSG" }
  ],
  "keyEvents": [
    { "year": 629, "event": "낭비성 전투", "role": "중당 당주, 단기 돌입" },
    { "year": 647, "event": "비담의 난 진압", "role": "진압군 지휘" },
    { "year": 660, "event": "황산벌 전투 · 백제 멸망", "role": "신라군 대장군" },
    { "year": 668, "event": "고구려 멸망", "role": "태대각간 (원정은 병으로 불참, 경주 수비)" }
  ],
  "traits": ["가야계", "화랑", "결사돌격", "내란진압"],
  "loyaltyBase": 90,
  "sourceReliability": "B",
  "bias": ["가문미화(김장청 행록 기반)"],
  "sources": [
    { "코드": "SGSG", "위치": "열전 제1~3 김유신 상·중·하", "등급": "B" }
  ],
  "note": "가야계 파벌의 구심점. 생존 중엔 파벌 결속도 하한 보정."
}
```

> 위 예시의 생몰년(595~673)과 사건은 삼국사기 김유신 열전에 따른다. 668년 평양 원정 불참 여부는 1-5 단계에서 원문으로 재확인한다.
