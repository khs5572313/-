# 1-1. 사료 체계 · 신뢰도 등급 · 출처 표기 규칙

> 모든 인물·사건 데이터는 이 문서의 **사료 코드**로 출처를 단다.
> URL은 작성 시점에 작업 환경의 네트워크 제한으로 접속 확인을 하지 못했다. 사용 전 한 번씩 접속해 확인할 것(표의 `확인` 칸에 체크).

| **X** | 위작 논란·전승·창작 | 『화랑세기』 필사본(박창화본), "양만춘" 이름 | 게임 내 「전승」 표시 필수, 정사로 취급 금지 |

**충돌 처리 원칙**
1. 등급이 높은 자료를 우선한다. 같은 등급이면 사건 당사국 기록과 상대국 기록을 함께 싣는다.
2. 연도가 서로 다르면 `연도_이설` 필드에 모두 기록한다. (예: 고구려-수 전쟁 병력 113만 3,800명은 수서 기준이며, 과장 가능성은 연구서로 표기)
3. 나무위키·위키백과는 **근거로 쓰지 않는다.** 원전과 연구서를 찾는 길잡이로만 쓴다.

## 6. 출처 표기 규칙 (데이터 입력 시)

```
"근거": [
  { "코드": "SGSG", "위치": "열전 제1 김유신 상", "등급": "B", "요지": "629년 낭비성 전투에서 홀로 적진 돌입" },
  { "코드": "ZZTJ", "위치": "권193 당기9", "등급": "B", "요지": "..." }
]
```
- `위치`는 권·편 이름까지 적는다. 원문을 인용할 땐 한문 원문과 번역을 함께 싣는다.
- 확인하지 못한 권 번호는 `"위치": "미확인"`으로 남긴다. **추정 권 번호를 적지 않는다.**
