## 2. 핵심 수치 3가지

| 수치 | 범위 | 뜻 |
|---|---|---|
| **파벌 결속도** | 0~100 | 가야계 장수들이 서로 뭉친 정도 |
| **왕실 신뢰도** | 0~100 | 신라 왕(플레이어)과 가야계 파벌 사이의 신뢰 |
| **개인 충성도** | 0~100 | 장수 개인 수치. `loyaltyBase` + 아래 보정 |

### 개인 충성도 계산

```
개인충성도 = loyaltyBase
           + (왕실신뢰도 − 50) × 0.4
           + (파벌결속도 − 50) × 0.2      ← 파벌이 단단할수록 지도부 결정을 따름
           + 포상·관직 보정
           − 골품 차별 보정 (아래 3절)
```

## 3. 골품제 연동 (교육 요소)

| 신분 | 관직 상한 | 가야계 특이 규칙 |
|---|---|---|
| 진골 (왕실 김씨) | 상한 없음, 왕위 계승 가능 | — |
| 진골 (가야계) | 상한 없음 (대각간·태대각간 가능) | **왕위 계승 불가**. 상대등에 임명하면 왕실 진골 귀족 불만 +10 |
| 6두품 (강수 등) | 6관등 아찬까지 | 중아찬 제도로 한계 일부 완화 |

※ 가야계 진골이 왕위 계승에서 차별받았다는 것은 김유신 가문이 왕이 되지 않았다는 사실에 근거한 **게임 설계상 규칙**이다. 이를 직접 명시한 사료가 있는 것은 아니다.

## 4. 파벌 상태와 효과

| 결속도 · 신뢰도 | 상태 | 효과 |
|---|---|---|
| 신뢰 70 이상 & 결속 60 이상 | **혼인동맹** | 가야계 장수 카드 비용 −1, 「철기 돌격」 등 가야 철기 카드 해금, 김유신 「화랑 결사」 강화 |
| 신뢰 40~69 | **협력** | 기본 상태 |
| 신뢰 20~39 | **불신** | 가야계 장수 출진 시 20% 확률로 지휘 거부, 내정 효율 −15% |
| 신뢰 20 미만 & 결속 70 이상 | **이반 위기** | 가야계가 비담 같은 반왕 세력과 손잡을 수 있음 → 내란 이벤트. (본편에서는 내란까지만. 독립 가야 부흥은 **DLC**에서 연결) |

## 6. 구현 메모 (코드용)

```ts
// 2단계 이후 src/strategy/factions/gaya.ts 로 옮긴다
interface FactionBloc {
  id: "gaya";
  cohesion: number;   // 파벌 결속도
  royalTrust: number; // 왕실 신뢰도
  leaderId: string | null; // 생존한 최고위 가야계 장수
}
```

- 상태 판정은 매 계절 시작 시 1회 실행한다.
- 이벤트 조건과 효과는 JSON 이벤트 스크립트로 분리한다 (4단계).
