# 약술형 논술 문제 유형 정의 및 사례

## TYPE-A: 첫 어절 ~ 끝 어절 찾기

### 정의
글쓰기 계획(보기)의 조건 ①②에 해당하는 기능을 수행하는 문장을 제시문에서 찾아,
해당 문장의 **첫 어절**과 **마지막 어절**을 쓰는 유형.

### 풀이 절차
1. 보기의 조건(①②)을 읽고 **기능**을 파악한다
   - "구체적 사례 제시", "권위자 견해 인용", "문제점 언급", "수치 제시" 등
2. 제시문을 문단별로 훑으며 해당 기능을 수행하는 **문장 하나**를 찾는다
3. 그 문장의 첫 어절(조사 포함)과 마지막 어절(마침표/물음표 앞 어절)을 쓴다

### 오답 주의
- 첫 어절만 맞고 끝 어절이 틀리면 **0점** (세트 채점)
- 문장이 아닌 문단 전체를 선택하면 오답
- "있다." → 끝 어절 = "있다" (마침표 미포함)

### 실제 기출 사례

**24학년도 A형 1번 (화법과 작문)**
```
[보기 조건]
① 시청 관련 부서에서도 필요성을 인지하고 있다는 사실을 언급한다
② 생활 체육관이 지역 사회에 주는 효용을 구체적으로 언급한다

[정답]
① 첫어절: 개선   끝어절: 있었다
② 첫어절: 각종   끝어절: 있다
```

**24학년도 A형 8번 (문학 - 기 갈래)**
```
[보기 조건]
㉠ 관직자로서 경계해야 할 그릇된 행동을 의문형 문장으로 전달
㉡ 초천에 돌아와 집 이름을 짓고 이 글을 썼음을 드러냄

[정답]
① 첫어절: 관직에   끝어절: 훔치겠는가
② 첫어절: 초천에   끝어절: 보인다
```

**26학년도 1번 (화법과 작문 - 협상)**
```
[보기 조건]
① 자신의 제안이 상대방에게 더 이익이 된다는 점을 근거로 수용 유도
② 상대방의 제안을 수용하는 대신 추가적인 요구를 함

[정답]
① 첫어절: 토지가   끝어절: 않겠습니까
② 첫어절: 저희가   끝어절: 주십시오
```

## TYPE-B: 빈칸 추론 (제시문 어구 찾아 쓰기)

### 정의
&lt;보기&gt;의 빈칸 ①②③에 들어갈 적절한 **말(어구/단어/문구)**을 제시문에서 찾아
그대로 옮겨 쓰는 유형. 가장 빈출.

### 풀이 절차
1. 보기 문장에서 빈칸의 앞뒤 맥락을 파악한다
2. 빈칸이 설명하는 **개념의 범주**를 파악한다 (상위 개념인지 하위 개념인지)
3. 제시문에서 그 개념이 **정의·설명된 부분**을 찾아 동일 표현으로 쓴다

### 핵심 원칙
- **제시문의 표현을 바꾸면 오답** → 동의어·유사어 불인정
- 이중 괄호 규정: 한글+한자 병기 시 한글 맞으면 인정

### 실제 기출 사례

**24학년도 A형 2번 (독서 - 라캉 이론)**
```
[보기]
상상계에서 아이는 ( ① )에 투영된 이미지를 통해 자아를 형성한다.
( ② )에서 인간은 언어를 통해 욕망을 추구하기 때문에 욕망은 언어에 종속된다.

[정답]
① 거울
② 상징계
```

**24학년도 B형 2번 (독서 - 클라우드)**
```
[보기]
가상 머신은 자체 ( ① )에 의해 독립적으로 작동된다.
이를 가능하게 하는 역할을 하는 것이 바로 ( ② )이다.

[정답]
① 운영 체제 (Operating System도 인정)
② 하이퍼바이저 (Hypervisor도 인정)
```

**26학년도 4번 (독서 - AI 강화학습)**
```
[보기]
㉠은 미래에 대한 최선의 예측은 ( ① )에만 의존함을 전제한다.
감쇄 계수가 감소할수록 ( ② )보다 ( ③ )를 중시한 판단이 이루어진다.

[보기2] 과거, 현재, 미래

[정답]
① 현재   ② 미래   ③ 현재
```

## TYPE-C: 음운 변동 찾기

### 정의
밑줄 친 단어/표현의 발음에서 일어나는 **음운 변동**을 보기 목록에서 골라 쓰는 유형.

### 7대 음운 변동 (필수 암기)

| 변동명 | 정의 | 대표 예시 |
|-------|-----|---------|
| 비음화 | 파열음→비음 (ㄱ·ㄷ·ㅂ → ㅇ·ㄴ·ㅁ) | 받는다→[반는다] |
| 유음화 | ㄴ → ㄹ (ㄹ 앞뒤) | 칼날→[칼랄] |
| 된소리되기 | 예사소리→된소리 | 특정→[특쩡] |
| 거센소리되기 | ㅎ + 예사소리 → 거센소리 | 지급하다→[지그파다] |
| 구개음화 | ㄷ·ㅌ + 이→ ㅈ·ㅊ | 닫히다→[다치다] (2단계) |
| 모음 탈락 | ㅡ·ㅏ 등 탈락 | 가아서→[가서] |
| 반모음 첨가 | 반모음 ㅣ/ㅗ 첨가 | 가서→[가여서] (방언) |

### 복합 변동 사례 (주의)
- **닫히다** → [다치다]: 거센소리되기(ㄷ+ㅎ→ㅌ) + 구개음화(ㅌ+이→ㅊ)
- **같이** → [가치]: 거센소리되기 + 구개음화

### 실제 기출 사례

**24학년도 A형 5번**
```
ⓐ 특정 → [특쩡]: 된소리되기
ⓑ 받는다 → [반는다]: 비음화
ⓒ 지급하더라도 → [지그파더라도]: 거센소리되기
```

**24학년도 B형 6번**
```
① 칼날 → [칼랄]: 유음화
② 국물 → [궁물]: 비음화
③ 닫히다 → [다치다]: 거센소리되기 + 구개음화
```

**25학년도 6번 (문장 내 밑줄 변동)**
```
㉡ 가서 → 모음 탈락
㉢ 난리가 → 유음화 (ㄴ이 ㄹ 앞)
㉣ 걷히자 → 거센소리되기 + 구개음화
```

## TYPE-D: 개념어 분류·적용

### 정의
보기에 제시된 **개념어 목록**에서 적절한 것을 골라 ㉠~㉣ 빈칸에 넣는 유형.
분류 기준(두 가지 이상의 속성)을 이해하고 사례에 정확히 적용해야 함.

### 풀이 절차
1. 보기의 개념어 목록과 각 개념의 **정의**를 제시문에서 파악한다
2. ㉠~㉣ 각 빈칸의 사례에서 **두 가지 속성의 조합**을 확인한다
3. 조합에 맞는 개념어를 배정한다

### 실제 기출 사례

**24학년도 D형 4번 (공공재 분류)**
```
[보기] 사적 재화, 클럽재, 공유 자원, 공공재

분류 기준:
- 배제성(O/X) × 경합성(O/X) 4가지 조합

㉠ 한산한 고속도로 = 배제O, 경합X → 클럽재
㉡ 꽉 막힌 고속도로 = 배제O, 경합O → 사적 재화
㉢ 출퇴근 시간 일반도로 = 배제X, 경합O → 공유 자원
㉣ 심야 일반도로 = 배제X, 경합X → 공공재
```

**25학년도 4번 (형법 과실 개념)**
```
[보기] 고의, 과실, 주의 의무

㉠ 보복 운전 목적 사고 → 고의
㉡ 졸음운전 사고 → 과실
㉢ "행위자가 ___을 다하였더라도" → 주의 의무
㉣ "___이 인정되지 않더라도" → 고의
```

**26학년도 5번 (행동경제학)**
```
[보기] Ⅰ 체계, Ⅱ 체계, 지불할 의사, 수용할 의사

㉠ 일상적 해결 방법과 편향이 연결된 것 → Ⅰ 체계
㉡ 부존자원 효과: ___가 ___보다 높음 → 수용할 의사 > 지불할 의사
```

## TYPE-E: 수치·표 계산 적용

### 정의
제시문의 공식·원리를 실제 수치 사례(보기)에 적용하여 **숫자·날짜**를 도출하는 유형.

### 풀이 절차
1. 제시문의 **계산 공식** 또는 **적용 원리**를 정확히 파악한다
2. 보기에 제시된 **수치 조건**을 공식에 대입한다
3. 단위·방향(왼쪽/오른쪽 등)까지 정확히 쓴다

### 실제 기출 사례

**24학년도 B형 5번 (대저울·전자저울)**
```
[공식] 물체무게 × 받침점거리 = 추무게 × 받침점거리

[조건] 왼쪽 30cm에 추 10kg, 오른쪽 20cm에 물체 ㉮
물체무게 × 20 = 10 × 30 → 물체무게 = 15kg

[전자저울] 10kg당 2cm 늘어남 → 15kg이면 3cm 늘어남
초기 10cm + 3cm = 13cm

[정답] ① 15 ② 13
```

**24학년도 G형 4번 (부의 소득세)**
```
[조건] 최소 보장 30만원, 소득 1만원 증가시 보조금 5천원 감소

소득 0원 → 처분가능소득 = 보조금만 = 30만원
소득 20만원 → 처분가능소득 36만원 → 보조금 = 36-20 = 16만원
보조금 감소 = 30-16 = 14만원

[정답] ① 30 ② 16 ③ 14
```

**26학년도 3번 (회계 장부 비교)**
```
[B사원 복식부기 장부]
6월 5일: 비품구매(컴퓨터) 3억 / 미지급금 3억
6월 15일: 미지급금 3억 / 현금 3억

거래 발생일 = 6월 5일 (비품 구매가 발생한 날)
현금 지출일 = 6월 15일 (실제 현금 지급일)

[정답] ① 6월 5일 ② 6월 15일 ③ A(사원)
```

## TYPE-F: 주제통합·상호텍스트 독해

### 정의
두 제시문(가)+(나) 또는 제시문+보기1을 함께 읽고, 이를 연계·통합하여
빈칸을 채우는 유형. 주로 문학 영역에서 출제.

### 구조 패턴
```
[제시문] (가) 작품 A  +  (나) 작품 B
[보기1] 외부 자료 (이론/사례)
[보기2] (가)와 (나)를 ___로 이해한 것 → ①② 빈칸 채우기
```

### 실제 기출 사례

**24학년도 A형 9번 (소설+시, 6.25 배경)**
```
[보기]
(가)에서 '( ① )'은 비극적이고 냉혹한 전쟁의 속성을 강조하는 데 사용된다.
(나)에서 '( ② )'는 폐허와 대비되어 화자의 의식이 긍정적으로 전환되게 하는 소재이다.

[정답]
① 눈 (오상원 「유예」의 핵심 소재)
② 개나리 (구상 「초토의 시 1」의 핵심 소재)
```

**24학년도 A형 3번 (독서, 주제통합)**
```
[보기1] 제임스 조이스의 실험적 글쓰기 사례
[보기2] 라캉의 이론으로 해석

조이스의 기존 규칙 거부 = ( ① ) 추구
조이스의 '애매 폭력적 언어' = ( ② )를 통해 자기 법칙 생산

[정답]
① 주이상스 (현실 쾌락 원칙 초월)
② 생톰 (고유한 증상/행위)
```

## TYPE-G: 조건형 서술 (25~26 신경향)

### 정의
답안의 **형식(어미·표현)**과 **글자 수**를 조건으로 지정하여 쓰는 유형.
25학년도 첫 등장, 26학년도 강화.

### 조건 유형
- 어미 조건: `-기 때문이다`, `-(으)로`, `-는` 등
- 글자 수 조건: "12자 이내", "6자 이내" (띄어쓰기·문장부호 제외)
- 어절 수 조건: "세 어절로", "두 어절로"
- 복합: 어미 + 글자 수 동시 지정

### 실제 기출 사례

**25학년도 2번 (아웃소싱 그래프 적용)**
```
[조건]
① '-기 때문이다' 형식, 12자 이내
② '-(으)로' 형식, 6자 이내

[정답]
① 고정비가 있기 때문이다 (혹은 '고정비가 발생하기 때문이다')
② 왼쪽(방향)으로
```

**26학년도 2번 (복식부기 거래 이중성)**
```
[조건]
① '-고'의 형식, 4자 이내
② '-는'의 형식, 4자 이내

[내용] 1억 원을 갚을 때 자산은 ( ① ) 부채가 ( ② ) 이중성
[정답]
① 감소하고 / 줄어들고 / 적어지고 등
② 감소하는 / 줄어드는 / 적어지는 등
```

**26학년도 6번 (차마설 - 세 어절)**
```
[조건]
① 제시문에서 찾아 세 어절로 쓰기
② 해당 문장의 첫 어절과 마지막 어절

[정답]
① 노둔하고 야윈 말 (세 어절 정확히)
② 첫어절: 임금은   끝어절: 것이다
```
