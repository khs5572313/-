# 약술형 논술 국어 문항 분석 스킬

## 개요

이 스킬은 대학별 약술형 논술 국어 기출 문항을 분석하여 수험생과 강사에게
실용적인 인사이트를 제공한다. 분석 결과는 **인터랙티브 위젯**, **블로그 HTML**, **유튜브용 PPT** 세 가지 형식으로 출력할 수 있다.

---

## 분석 절차

### Step 0: 자료 확인
- 제공된 PDF/텍스트에서 연도별·유형별 문항 전수 파악
- 각 문항의 구성 요소 추출: 출제영역, 핵심개념, 제시문, 문제, 정답, 채점기준

### Step 1: 데이터 수집 (문항별 파싱)

각 문항에서 다음을 추출한다:

```
- 학년도 / 유형코드 (A형, B형...) / 문항번호
- 출제영역: 화법과작문 | 독서 | 언어와매체 | 문학
- 핵심개념 및 용어
- 예상 소요 시간
- 제시문 주제 및 분야 (인문/사회/과학/문학 등)
- 문제 유형 분류 (아래 유형 분류표 참고)
- 정답 (①②③ 각각)
- 배점 구조
- 채점 기준 특이사항
```

### Step 2: 문제 유형 분류

아래 7가지 유형으로 분류한다. 세부 정의는 [references/question-types.md] 참고.

| 유형코드 | 유형명 | 핵심 특징 |
|---------|-------|---------|
| TYPE-A | 첫끝어절 찾기 | 조건→문장 매칭→첫/끝어절 |
| TYPE-B | 빈칸 추론 (제시문 어구) | ①②③ 빈칸에 제시문 표현 그대로 |
| TYPE-C | 음운 변동 찾기 | 보기 목록에서 변동명 선택 |
| TYPE-D | 개념어 분류·적용 | 보기 개념어→빈칸 적용 |
| TYPE-E | 수치·표 계산 적용 | 원리 이해 후 숫자/날짜 도출 |
| TYPE-F | 주제통합·상호텍스트 | (가)(나) 복수제시문 연계 |
| TYPE-G | 조건형 서술 | 형식 조건(-기 때문이다 등) + 글자 수 제한 |

### Step 3: 제시문 경향성 분석

**독서 제시문 분야 분류:**
- 인문·철학 (논리학, 철학 이론, 윤리학, 행동경제학 등)
- 사회·경제 (경제 제도, 법률, 미디어, 사회 현상)
- 과학·기술 (물리, 화학, 컴퓨터, AI, 의학)
- 예술·문화 (미술, 음악, 언어학)

**문학 제시문 구성 패턴:**
- 복수 작품 제시 비율 (가+나 구성 여부)
- 갈래 조합 (현대시+고전산문, 소설+시 등)
- 교과서 수록 여부
- 시대·역사 맥락 결합 여부

### Step 4: 채점 기준 패턴 분석

1. **정확 일치 원칙** - 부분 점수 허용 여부
2. **세트 채점 여부** - 첫끝어절 양쪽 동시 정답 여부
3. **한글/한자 병기 규정** - 표기 변이 허용 범위
4. **순서 교환 허용** - ①②의 순서가 바뀌어도 되는 경우
5. **배점 구조** - 문항별 배점 분포 (2·3·4·5·6·7점 등)

### Step 5: 연도별 변화 추적

3개년 이상 자료가 있을 경우:
- 유형별 출제 빈도 변화
- 신규 유형 등장 시점
- 출제 영역 비중 변화
- 난이도 변화 신호 (조건 강화, 복합 유형 증가 등)

### Step 6: 출력 형식 결정

사용자 요청에 따라 아래 세 가지 출력 중 하나(또는 복수)를 선택한다:

| 요청 표현 | 출력 형식 | 참고 파일 |
|---------|---------|---------|
| 기본 분석, 채팅에서 바로 보기 | 인터랙티브 위젯 | references/visualization-template.md |
| "블로그에 올리고 싶다", "HTML로 저장" | 독립 HTML 파일 | references/visualization-template.md |
| "PPT로 만들어줘", "유튜브 슬라이드", "발표 자료" | pptx 파일 | references/ppt-template.md |

## 출력 A: 인터랙티브 위젯 (기본)

`visualize:show_widget` 도구로 인터랙티브 HTML 위젯을 생성한다.
→ 구조·CSS·HTML 뼈대: [references/visualization-template.md] 참고

필수 6섹션:
```
① 통계 요약      - 학년도수, 유형수, 문항수, 시간, 배점 등 핵심 수치
② 문제 유형 패턴 - 7유형 각각 설명 + 실제 문제 사례 + 정답
③ 제시문 경향성  - 독서 분야 분류표 + 문학 구성 패턴
④ 연도별 변화    - 테이블 형식으로 연도별 출제 특징 비교
⑤ 채점 기준      - 핵심 원칙 + 배점 구조 + 오답 주의사항
⑥ 대비 전략      - 유형별 풀이 전략 (실용적·구체적으로)
```

## 출력 B: 블로그용 독립 HTML 파일

사용자가 "블로그에 올리고 싶다", "HTML 파일로 저장해줘" 요청 시 생성.

**작성 규칙:**
- `<!DOCTYPE html>` 포함 완전한 HTML 문서 구조
- 외부 CDN 의존 없음 — CSS/JS 전부 인라인
- 다크모드 자동 지원: `prefers-color-scheme: dark` + CSS 변수
- 반응형: `max-width: 860px`, 모바일 `@media (max-width: 600px)` 그리드 1열
- 탭 네비게이션: JS로 섹션 전환
- 파일 저장: `/mnt/user-data/outputs/{대학명}_약술논술_분석.html`

---

## 출력 C: 유튜브·강의용 PPT (pptx)

사용자가 "PPT로 만들어줘", "유튜브에 올릴 슬라이드", "발표 자료" 요청 시 생성.

→ **상세 코드 패턴은 반드시 [references/ppt-template.md] 먼저 읽고 진행할 것**

### PPT 생성 절차

**1단계: 의존성 확인**
```bash
node -e "require('pptxgenjs'); console.log('OK')"
# 실패 시: npm install -g pptxgenjs react react-dom sharp react-icons
```

**2단계: JS 스크립트 작성** (`/home/claude/make_ppt.js`)
- [references/ppt-template.md]의 팔레트·아이콘·슬라이드 패턴 참고
- 대학명, 분석 연도, 유형 데이터를 실제 분석 결과로 채워 작성

**3단계: 실행 및 저장**
```bash
node /home/claude/make_ppt.js
# 출력: /mnt/user-data/outputs/{대학명}_약술형논술_분석.pptx
```

**4단계: QA (필수)**
```bash
python3 /mnt/skills/public/pptx/scripts/office/soffice.py \
  --headless --convert-to pdf /mnt/user-data/outputs/{파일명}.pptx
rm -f slide-*.jpg
pdftoppm -jpeg -r 150 {파일명}.pdf slide
ls -1 "$PWD"/slide-*.jpg
# view 도구로 각 슬라이드 이미지 육안 확인
# 겹침·텍스트 넘침·빈 슬라이드 발견 시 좌표 수정 후 재실행
```

**5단계: 파일 전달**
```
present_files(["/mnt/user-data/outputs/{파일명}.pptx"])
```

### PPT 표준 슬라이드 구성 (11슬라이드)

| # | 제목 | 배경 | 주요 내용 |
|---|------|------|---------|
| 01 | 타이틀 | navy | 대학명·분석기간·4개 정보카드·유튜브 채널 배지 |
| 02 | 통계 요약 | offW | 6개 stat-box (3×2 그리드) + 하단 포인트바 |
| 03 | 유형 개요 | navy | 좌4개 세로+우빈도 / 하단3개 가로 |
| 04 | TYPE-A 상세 | offW | 3단계 플로우 + 기출 3사례 카드 |
| 05 | TYPE-B/C | offW | 좌:B형 사례 / 우:C형 7변동표 |
| 06 | TYPE-D·E·F·G | offW | 2×2 카드 그리드 |
| 07 | 제시문 경향성 | navy | 독서 5분야 + 문학 6특징 |
| 08 | 연도별 변화 | offW | 연도별 테이블 (헤더+데이터행) |
| 09 | 채점 기준 | navy | 5원칙 + 4배점규칙 + 오답주의 |
| 10 | 대비 전략 | offW | 4유형 2×2 전략카드 |
| 11 | 마무리 | navy | 핵심정리 + 유튜브배지 + 학원정보 |

## 중요 원칙

1. **실제 문제 사례 반드시 포함** — 각 유형마다 기출 원문과 정답 제시
2. **추상적 설명 금지** — 구체적 문항 번호와 내용 명시
3. **채점 기준은 공식 문서 기준** — 선행학습 영향 평가 보고서 인용
4. **연도 비교 필수** — 단일 연도 분석은 불완전
5. **시각화 우선** — 텍스트 나열보다 위젯·PPT로 직관적 전달
