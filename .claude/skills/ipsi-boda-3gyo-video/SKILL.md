# 입시를 보다 · 주간 3교 비교 영상 제작

유튜브 채널 「입시를 보다」에 매주 올리는 **3개 대학 2028 변경점 비교 영상**의 재료를 만든다.
산출물은 ① 16:9 PPT(슬라이드마다 촬영 대본을 발표자 메모로) ② 썸네일 3안 PNG ③ 유튜브 설명란 텍스트 ④ 팩트체크 결과표다.

**이 스킬은 대학을 다시 분석하지 않는다.** 내용은 전부 28계획 프로젝트의 판독 문서에서 가져온다.
형식(구조·디자인·대본 말투·검증 규칙)만 이 스킬이 고정한다.

## 0. 입력과 전제

- 사용자가 말하는 것: 이번 회차 3개 대학(예: 서강대·성균관대·한양대), 회차 번호(없으면 편성표에서 찾는다)
- 프로젝트에서 읽는 것 (대학마다):
  - `claude/{대학}_27-28_변경사항_판독.md` — 1차 원천
  - `claude/교차표_조각/{대학}.md` — 판독 md와 값이 다르면 **판독 md 우선**, 차이를 팩트체크 표에 기록
  - `claude/calc/{대학}_27-28_계산.md` — 시뮬레이션 수치 확인용
- 판독 md가 없는 대학이 있으면 **즉흥으로 채우지 않는다.** 사용자에게 알리고 `jeonhyeong-byeonhwa-pandok`으로 먼저 판독하자고 제안한다.
- 편성표 `claude/유튜브_편성표.md`를 읽는다(없으면 이번 회차에 만든다). 이미 다룬 대학, 다음 회차 예고, 각 회차가 쓴 판독 버전을 기록하는 곳이다.

## 1. 헤드라인 고르기 (대학별 2~3개)

판독 md의 「헤드라인」·「GATE 7 일반해」·「STEP 9 추정」에서 고른다. 우선순위:

1. 학생·학부모가 **행동을 바꿔야 하는 것** — 지원 가능 여부, 수능최저, 중복지원, 과목 선택
2. **숫자가 크게 움직인 것** — 인원 ±100명 이상, 비율 ±5%p 이상, 배점 2배 이상
3. **직관과 반대인 것** — 순위 역전, 「폐지」인데 예외가 있음, 「유지」인데 실질이 바뀜

판독 md가 「대조 불가」「미기재」로 둔 항목은 헤드라인으로 쓰지 않는다. 「확정 요강에서 확인할 것」 슬라이드로 보낸다.

## 3. 디자인 규칙

- 16:9 (13.333 × 7.5 in), 다크 배경 `0E1726`, 카드 `17243A` / `22324F`, 본문 `F1F5F9`, 보조 `CBD5E1`, 흐린 글자 `8C9BB0`
- 강조 앰버 `F2B544`, 상승 `34D399`, 하락 `F87171`, 27년 막대 `64748B` · 28년 막대 앰버
- 대학 색은 칩과 표 머리에만 쓴다. 로고·교표는 쓰지 않는다. 대학 색 참고: 서울대 `4FB3BF`, 연세대 `5B8DEF`, 고려대 `E0526B` — 새 대학은 서로 구분되는 채도의 색을 고르고 편성표에 기록해 회차 간 일관되게 쓴다
- 글꼴 Malgun Gothic. 제목 28pt, 본문 13~15pt, 표 13pt
- 모든 데이터 슬라이드 하단에 출처 한 줄: 「자료: 각 대학 2028 입학전형 시행계획(심의 전) · 2027 수시/정시 모집요강 — 문약 판독」
- 차트는 pptxgenjs 네이티브 차트. 테두리 줄무늬·제목 밑줄 장식 금지

## 4. 대본 (발표자 메모)

- 각 슬라이드 메모 첫 줄은 `〔N〕 슬라이드 제목`. 대본 본문이 그대로 이어진다
- 표기: `( )` = 동작·연출, `★` = 힘주어 말할 문장이자 자막 강조 후보 (메모 칸은 굵게가 안 되므로 ★로 대신한다)
- 말투: 학부모와 고2가 함께 듣는 존댓말, 문장 짧게. 화면 숫자는 읽기만 하고 다시 풀지 않는다
- 오프닝 첫 문장은 가장 강한 헤드라인 한 줄(훅) → 인사 → 대상(현 고2)·자료 출처·심의 전 주의
- 목표 러닝타임 20~25분 (1분 ≈ 300자)
- 부록 슬라이드 메모에 촬영 안내·반드시 말할 단서·쇼츠 후보 4개를 넣는다
- 대본 원문은 같은 내용을 Claude Docs 문서로도 남긴다(사용자가 편집하면 메모에 다시 반영)

구현 메모: pptxgenjs로 만든 뒤, 전 슬라이드를 돌며 기존 notes 객체를 지우고 `notes.js` 배열로 다시 넣는다. 배열 길이와 슬라이드 수가 다르면 빌드를 멈춘다. 빌드 후 python-pptx로 슬라이드별 메모 첫 줄이 번호와 맞는지 출력해 확인한다.

## 5. 썸네일 3안

- 1280×720 PNG, HTML + Playwright로 렌더, Noto Sans CJK KR Black 계열
- A 충격형(가장 반직관적인 숫자) / B 정보형(「2028 ○○·○○·○○ 이렇게 바뀐다」 + 대학별 한 줄) / C 공감형(학생 유형 한 줄 + 순위·점수 카드)
- 자극적인 문구(A·C)에는 카드 아래에 조건을 작게 단다(「인문계 · 원문 산출식 기준」, 「가상 학생 기준」 등)
- 사용자가 얼굴 사진을 주면 오른쪽 카드 자리에 배치한 변형을 추가로 만든다

## 6. 유튜브 설명란 텍스트

한 파일(`설명란_#N.txt`)로 낸다: 한 줄 요약 → 챕터 목록(타임스탬프는 `00:00` 자리표시) → 자료 출처와 심의 전 주의 → 「시뮬레이션은 가상 학생 기준, 합격 예측 아님」 → 해시태그 5~8개.

## 7. 팩트체크 게이트 (전달 전 필수)

모든 숫자·주장을 판독 md 원문과 대조하고 아래 규칙을 하나씩 확인한다. 결과는 「슬라이드 / 문제 / 수정」 표로 사용자에게 보여 준다. 고칠 게 없으면 「통과」라고 적는다.

1. **분모 통일** — 한 차트 안의 대학들은 같은 기준(수시 정원 내 / 정원 내 전체 / 정원 외)이어야 한다. 정원 외 인원이 섞이지 않았는지 본다.
2. **표기 배점 ≠ 실제 차이** — 기본점수·최저점이 있는 배점은 「실제 점수 차 최대 ○점」을 함께 적는다.
3. **「폐지」의 예외** — 의학과·특정 모집단위 예외가 있으면 괄호로 병기한다.
4. **중복지원은 새로 풀린 조합만** — 27에도 가능했던 조합을 「새로 두 장」처럼 말하지 않는다.
5. **원인 설명은 판독 md의 설명대로** — 숫자가 맞아도 이유를 다르게 말하면 틀린 것이다.
6. **판독 md에 없는 해석 문장 금지** — 필요하면 「해석」이라고 밝히거나 뺀다.
7. **두 분모에서 부호가 갈리는 지표는 병기** — 예: 재수생 자리 정원 내 전체 −, 수시만 +.
8. **미기재·대조 불가 항목을 단정하지 않는다** — 「확인할 것」으로 보낸다.
9. **시뮬레이션에는 「가상 학생 기준, 합격 예측 아님」** 을 대본과 화면에 모두 둔다.
10. **자극적 문구에는 조건 자막** — 썸네일·쇼츠·오프닝 훅.
11. **교차표 조각과 판독 md가 다르면 판독 md 값**을 쓰고 차이를 표에 남긴다.

## 8. 전달과 기록

- 파일명: `입시를보다_#{회차}_{대학1}{대학2}{대학3}_v{n}.pptx`, `썸네일_#{회차}_{A|B|C}.png`, `설명란_#{회차}.txt`
- 편성표 `claude/유튜브_편성표.md`에 한 행 추가: 회차 · 날짜 · 세 대학 · 각 대학 판독 버전(v6 등) · 다음 회차 예고 대학
- 판독 md가 나중에 새 버전으로 갱신되면, 편성표에서 옛 버전을 쓴 회차를 찾아 「업데이트편 후보」로 알려 준다
- 전달 메시지는 짧게: 무엇을 만들었는지, 팩트체크에서 고친 것, 사용자가 확인할 것(예고 대학, 자극적 문구 사용 여부)
